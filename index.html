vc-rs

Windows向け RVC音声変換アプリ

マイク入力やWAVファイルを、RVCモデルで別の声に変換するアプリです。Rustで実装しており、GUI・CLI・VST3プラグインを配布しています。

Windows x64 / 日本語・英語UI / MIT License

ダウンロード GitHubでソースを見る

声のRVCモデルは別途必要です。ソースからビルドせずに使えます。

できること

リアルタイム音声変換
通常画面で声のモデル・入出力・音量・ピッチをまとめて操作できます。音量とピッチは即時反映され、設定は次回起動時も使えます。
モデルの準備
ONNX形式に対応。対応するRVC v2 / F0の.pthモデルはアプリ内で変換できます。補助モデルはセットアップや「モデル関連の設定」から取得でき、カスタムファイルも指定できます。
WAV変換・DAWでの利用
同梱のCLIでWAVファイルを変換できます。DAW向けにはVST3版を用意しています。

ダウンロードと対応環境

配布先はGitHub Releasesです。単体で使う場合は、まずWindows MLのGUI版を選んでください。

パッケージ用途・環境必要なもの・注意点
Windows MLGUI + CLINVIDIA以外を含む幅広いGPU向けWindows App SDK Runtime 2.1以上
TensorRTGUI + CLINVIDIA GPU向け最新のNVIDIAドライバ。配布は約1.9GBで、初回にエンジン構築が必要です。
VST3プラグインDAWで使う場合Windows ML版・TensorRT版があります。導入ガイド

GUIのWindows ML版は vc-rs-windowsml-…zip を選んでください。ランタイムはこちらから入手できます。

声のモデルは同梱していません。ContentVec・RMVPEの補助モデルはGUIから取得でき、合計約741MBです。

使い始め方

  1. ZIPを展開し、vc-gui.exeを開く

    DLLは同じフォルダに置いたままにしてください。初回は表示言語を選び、利用条件を確認します。

  2. マイクと声のモデルを設定する

    セットアップの案内に沿って入出力を確認し、RVCモデルを選びます。不足する補助モデルはアプリから取得できます。

  3. 準備を完了し、通常画面を開く

    必要なモデルや処理部品の準備ができたら、「通常画面へ」で設定を保存します。この時点では音声変換は始まりません。

  4. 通常画面の「開始」で変換する

    変換音を聴きながら音量・ピッチを調整します。モデルやデバイスなど、再起動が必要な変更は画面上部に表示されます。「再起動」で反映し、「停止」で変換を終了します。

接続方式やノイズ低減は「音声デバイス・ノイズ低減」、GPUや遅延の調整は「バックエンド詳細」にあります。言語の切り替えとセットアップの再開は、通常画面を下までスクロールすると表示されます。

よくある質問

無料で使えますか？

vc-rs本体はMITライセンスの無料・オープンソースソフトウェアです。声のモデルや補助モデルには、それぞれの利用条件が適用されます。

声のモデルは付属していますか？

付属していません。利用条件を確認したRVC音声モデルをご用意ください。ContentVec・RMVPEの補助モデルはアプリから取得できます。

すべての.pthモデルを使えますか？

内蔵コンバータはRVC v2 / F0モデルに対応しています。v1などは事前のONNX変換が必要です。詳しくは対応モデルの説明をご確認ください。

DiscordやOBSでも使えますか？

仮想オーディオデバイスを経由して変換音を渡せます。vc-rsの出力を仮想デバイスの再生側に設定し、DiscordのマイクやOBSの音声入力には対応する録音側を選びます。ドライバの導入と接続先アプリの設定は手動です。

音が途切れたり、遅れたりするときは？

通常画面の「バックエンド詳細」でチャンクサイズを調整できます。まずは安定して動く設定を見つけ、その後に小さくして遅延を調整し、「再起動」で反映します。結果はGPUやモデル、設定で変わります。設定ガイドをご覧ください。
